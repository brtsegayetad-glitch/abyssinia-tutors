# Geez Custom Audio Recordings Folder

Place your custom voice recordings for the Ge'ez characters in this folder.
The app is engineered to automatically detect and play these custom files when a user clicks the corresponding Ge'ez letter!

## Recommended Filenames

You can name your audio files in **two ways** (the app supports both):

### Option 1: Unicode Character (Easiest & Most Direct)
Simply name the file exactly like the Ge'ez letter itself!
For example:
* `ለ.mp3` (or `.wav`, `.m4a`)
* `ሉ.mp3`
* `ሊ.mp3`
* `ላ.mp3`
* `ሌ.mp3`
* `ል.mp3`
* `ሎ.mp3`

### Option 2: Phonetic Transliteration (English Spellings)
Specifically for the **ለ (Le) Family**:
* `ለ` ➔ `le.mp3` (or `la.mp3`)
* `ሉ` ➔ `lu.mp3`
* `ሊ` ➔ `li.mp3`
* `ላ` ➔ `la.mp3`
* `ሌ` ➔ `lie.mp3` or `lee.mp3`
* `ል` ➔ `l.mp3` or `li-sixth.mp3`
* `ሎ` ➔ `lo.mp3`

## Supported Audio Formats
* **MP3 (`.mp3`)** — *Highly Recommended for best loading speed and universal browser support!*
* WAV (`.wav`)
* M4A (`.m4a`)
